# SocalApp

## Features
Клиент-серверное приложения социальной сети. Приложение включает ленту постов, ленту ивентов, страницу профиля, сервис авторизации. Есть возможность:
- Добавлять, удалять, редактировать (CRUD), лайкать посты.
- Регистрироваться, логиниться логаутиться в профиле.
- Добавлять в посты фото с камеры, картинки.

Приложение реализует архитектуру MVVM с соблюдением принципов SOLID, Clean Architecture, Single Activity.

## Стек
- Kotlin
- Clean Architecture
- Gradle
- MVVM
- Fragments
- Room
- Retrofit
- Coroutines, LiveData, Flow
- Paging3
- Hilt
- Gson
- ImagePicker, Glide
- Cicerone
